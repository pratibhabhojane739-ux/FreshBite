# FreshBite - Online Food Ordering Website

## Project Description
FreshBite is a responsive online food ordering website developed using HTML, CSS, and JavaScript. Users can browse food items, add them to the cart, and view the total amount.

## Features
- Responsive Design
- Food Categories
- Popular Menu
- Add to Cart
- Cart Counter
- Total Price Calculation
- About Us
- Contact Us

## Technologies Used
- HTML5
- CSS3
- JavaScript
